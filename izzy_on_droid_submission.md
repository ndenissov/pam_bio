# Заявка на включение PAM Bio в каталог IzzyOnDroid

Приложение **PAM Bio** готово для подачи в каталог **IzzyOnDroid**!

## Куда подавать заявку?

Заявка подается через создание нового **Issue** в официальном GitLab-репозитории IzzyOnDroid:
👉 **[https://gitlab.com/IzzyOnDroid/repo/-/issues/new](https://gitlab.com/IzzyOnDroid/repo/-/issues/new)**

---

## Инструкция по подаче:

1. Перейдите по ссылке: [https://gitlab.com/IzzyOnDroid/repo/-/issues/new](https://gitlab.com/IzzyOnDroid/repo/-/issues/new)
2. Если предложено выбрать шаблон (Description template), выберите **`App Inclusion Request`**.
3. В поле **Title** укажите:
   `Inclusion Request: PAM Bio`
4. В поле **Description** скопируйте и вставьте следующий готовый блок текста:

```markdown
**Title:** Inclusion Request: PAM Bio

**Description:**
Please consider adding PAM Bio to your repository.

- **App Name:** PAM Bio
- **Author/Developer:** Nikita Denissov (ndenissov)
- **Source Code Repository:** https://github.com/ndenissov/pam_bio
- **APK / Releases Link:** https://github.com/ndenissov/pam_bio/releases
- **License:** Apache License 2.0
- **App Description:** PAM Bio turns your Android smartphone into a biometric hardware security module for your Linux or Windows PC. Unlock your desktop, authenticate sudo requests, or bypass the Windows lock screen using your phone's fingerprint or face unlock—no YubiKey or extra hardware required.

**Additional Notes:**
- Provides local biometric security authentication over Wi-Fi (mDNS + TCP).
- Releases are published regularly as signed APKs in GitHub Releases.
- Uses Google ML Kit for fast local QR code scanning during pairing.
```

---

## Что произойдёт дальше?
Редактор IzzyOnDroid проверит заявку, добавит репозиторий в авто-сканирование, и при выпуске новых релизов на GitHub приложения будут автоматически появляться в каталоге F-Droid IzzyOnDroid.
